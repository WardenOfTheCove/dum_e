# dum_e
Iron man's infamous helper from the first movie. Powered with the Raspberry Pi Compute Model 5.

## Use of AI
This project did not use AI in any process of development.

## Tools used
- PCB Design: KiCAD
- 3D Design:
- Code Editor(s): Neovim and Visual Studio Code

 ## How it works
 The Compute Model runs an AI model which tracks user activities and commands.
 Commands can be a spoken prompt, a typed in command, or a command linked to RFID.

 ## Usage
 dum_e is my first major hardware project, so please be wary of bugs.
